# Video checklist (candidate narration)

The application asks for a short VIDEO where the candidate explains the code in
their OWN WORDS and shows green unit tests. Do not claim work was done without AI
if that is not true. Review the code before recording and describe the tools used.

Suggested 2-3 minute structure:

1. Show the application in the browser: enter one phrase; display organic results;
 download and open the JSON file.
2. Explain `public/index.html`, `public/app.js`, and `public/styles.css`.
3. Explain the `search.js` request to Serper: country/lang/page filters, use of
 `organic` only, and the normalized output structure.
4. Explain `server.js`: HTTP endpoint, secret API key stays on the server,
 request validation and simple rate limit.
5. Run `npm test` and show all passing tests on camera.
6. Mention use of AI development tools if asked or required, and be ready to
 explain the code without assistance in the next interview.

Do not use fabricated demo search results to imply a live Google integration.
