# ShortFactory — установка и ежедневная работа (26.10.2026)

## Не путать файлы

ZIP с двумя Roman MP4 — результаты для просмотра. **Он не устанавливает программу.**
Нужен отдельный файл `MoravianHost_ShortFactory_SETUP_2026-10-26.zip`.
Извлеки его один раз в Downloads: внутри папка `ShortFactory_SETUP`, в ней `INSTALL_SHORTFACTORY.cmd`.
Двойной щелчок по CMD запускает мастер, который копирует 13 компонентов, создаёт виртуальное окружение Python, устанавливает бесплатные зависимости и регистрирует задачу Windows.

Рабочее место: существующая папка `%USERPROFILE%\MoravianHost\MediaMachine\ShortFactory`, либо корень MediaMachine, если в нём уже есть trend_refresh_runner.py. Установщик НЕ трогает SQL/CRM, не уничтожает исходники и резервирует заменяемые файлы.

## Что после установки работает без дополнительных авторизаций

Каждый день (по умолчанию 08:43 местного времени, только когда доступна учётная запись Windows):
- просмотр `trend_candidates.auto.csv` из существующего ShortFactory и сохранение новых идей в `ideas/` как **НЕ ПРОВЕРЕНО**;
- выбор первого ещё не обработанного/вновь одобренного эпизода из `queue/ready/`;
- загрузка лицензированных исходников и модели Kokoro в локальный кэш (только в первый раз);
- 2 вертикальных варианта Action и Documentary с субтитрами и WAV без платного API;
- проверка H.264/AAC/1080×1920, SHA256 и лицензий; сохранение в `MoravianHost\MediaMachine\Drafts\ShortFactory\<episode_id>\`;
- если ничего нового — безопасный IDLE, без повтора старых публикаций.

По умолчанию там один пилотный эпизод `roman-training-demo.json`: рендер разрешён, но `editorial_approved=false`, поэтому **в YouTube он не загрузится до проверки**. Идеи из CSV не переводятся в очередь автоматически, так как тренд, лицензия на чужое видео и достоверность — разные вещи.

## Как подключить YouTube, один раз

1. Убедись в конкретном канале YouTube, куда разрешено загружать. В YouTube Studio: Settings → Channel → Advanced settings → Channel ID (начинается с UC).
2. В Google Cloud Console выбери проект, включи **YouTube Data API v3**. Настрой OAuth consent screen и OAuth client типа **Desktop app**. Скачай его JSON в безопасную локальную папку:
`%USERPROFILE%\.config\MoravianHost\ShortFactory\youtube_oauth_client.json`.
Не загружай ключ в ChatGPT/GitHub/Google Drive.
3. В установленной папке выполни:
`.venv\Scripts\python.exe shortfactory_youtube_private.py --authorize`
Откроется Google OAuth. Убедись, что выбрал правильный канал. Будет сохранён частный `youtube_token.json` в ту же локальную папку.
4. В `config\shortfactory_settings.local.json` поставь свой **проверенный** `channel_id` и `enable_private_upload: true`.
5. Перед отправкой конкретного выпуска просмотри оба файла, авторство, озвучку, CTA и дату. Только для проверенного выпуска меняй `editorial_approved` на true в соответствующем `queue\ready\<id>.json`. Проверь, что в нём тот же `channel_id`.
6. Следующий локальный запуск загрузит только **PRIVATE**, проверит канал и обратное чтение API, запишет `state\youtube\<id>.json` и ссылку. При ошибке загрузки статус HOLD, никаких автоматических повторов.

Без выполненных пунктов авторизации машина продолжает производить локальные файлы, но ничего не публикует. Прямая автопубликация PUBLIC намеренно выключена — сначала нужно подтверждение прав, безопасности и оригинальности, затем отдельное включение production.

## Как получать новые эпизоды

В `queue/ready` лежат JSON с отдельными `voice_spec` и `visual_spec`. Пример римского ролика показывает схему. Каждый новый **независимый** эпизод должен содержать проверенный сценарий, реальные доказательства/источники, набор разрешённых видео/фото с конкретными авторами, новый монтаж, один CTA, юридическое лицо и маркировку иллюстративной реконструкции. Идеи из `ideas/` — только отправная точка. Опционально можно поставить бесплатный Ollama и `qwen2.5:3b`; включение `enable_local_ollama_ideas` даёт черновики углов/хуков, **не** маркирует их как правдивые.

## Поддержка

- GitHub: https://github.com/aliaksei-chareshneu/alchareshneu/pull/67 (DRAFT, не production).
- При запуске `logs\daily-YYYY-MM-DD.log` — статус этапов.
- Windows Task Scheduler: `MoravianHost ShortFactory - daily private drafts`. Перезапуск задачи безопасен — сохранённые эпизоды/видео не дублируются.
- Если компьютер выключен или пользователь не вошёл, Windows может перенести либо пропустить запуск; это не облачная постоянная служба.
- Нет платных AI-видеокредитов, но есть стоимость электричества, диска, загрузок и ограничение компьютерных ресурсов.
- Серийные одинаковые ролики/слайд-шоу без собственной ценности могут не пройти монетизацию YouTube — https://support.google.com/youtube/answer/1311392.
- Один клиент/CRM, один существующий ShortFactory; `state/youtube` — техническая квитанция, не новый CRM.
