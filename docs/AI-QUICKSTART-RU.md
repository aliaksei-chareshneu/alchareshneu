# IMPERION AI — как пользоваться (Windows, 23.10.2026)

**Основной способ:** откройте локальную папку репозитория, перейдите в `ops` и дважды щёлкните **`IMPERION-AI.cmd`**. Появится меню. Вводить команды PowerShell для запуска не требуется, если Node.js уже доступен. Если компьютер выключен или Remote Desktop Commander offline, инструкция и файлы в GitHub сохраняются, но никакая программа на ПК не запускается автоматически.

Это **для кода и черновиков**, не вторая CRM, не менеджер рассылок и не бот для автоматической публикации. Единственный учёт лидов и постов — уже существующие формы и таблицы. Юридические роли и разрешения остаются раздельными.

## Что выбирать в меню

| Клавиша | Действие | Требует интернета / входа? |
| --- | --- | --- |
| **1. Status** | Git, VS Code, Codex, Antigravity, Ollama и проверка `127.0.0.1:11434` | Без внешних вызовов |
| **2. Tests** | Запускает Node-тесты, ничего не публикует | Нет |
| **3. Preview** | Синтетический пример и отпечаток исходника | Вообще нет сетевых вызовов |
| **4. Local smoke** | Три тестовых перевода CZ/RU/UK через Ollama, проверяет факты и язык | Только localhost |
| **5. VS Code** | Открывает проект. Встроенный GitHub Copilot Chat находится в VS Code | Для Copilot нужен вход/квота |
| **6. Codex** | Запускает CLI в этом проекте, по умолчанию **только чтение** | Нужна действующая авторизация ChatGPT |
| **7. Antigravity** | Запускает `agy` в режиме plan + sandbox | Нужны Google eligibility и квота |
| **8. Local chat** | Локальный диалог с Qwen на CPU, без сохранения переписки этой программой | Только localhost |
| **0** | Выход | — |

Из терминала в корне репозитория доступны те же операции:

`node ops/imperion-ai.cjs status`

`node ops/imperion-ai.cjs test`

`node ops/imperion-ai.cjs smoke`

`node ops/imperion-ai.cjs editor`

`node ops/imperion-ai.cjs codex`

`node ops/imperion-ai.cjs agy`

`node ops/imperion-ai.cjs chat`

Статусы проверяются **в момент выполнения**. Наличие файла или зелёный CI не означает, что аккаунт ассистента авторизован, подписка активна и реальная публикация осуществлена.

## Первая реальная задача для Codex / GitHub Copilot

1. Нажмите **5** — редактор откроет проект. Прочитайте `AGENTS.md`; для сайта и заявок — `docs/CODEX-SITE-CONVERSION.md`, для языковых черновиков — `docs/AI-CONTENT-PIPELINE.md`.
2. В VS Code откройте Chat и при необходимости нажмите **Use AI Features** → войдите в разрешённый GitHub-аккаунт. Проверьте бесплатную квоту/право на Copilot, **не покупайте** новый план автоматически.
3. Для работы через ChatGPT-аккаунт используйте **6 (Codex)**. Начните с фразы: «Прочитай AGENTS.md и существующие тесты. Изучи конкретную задачу. Предложи минимальный план с проверяемыми критериями, без правок и без публикации».
4. Если согласны с планом, отдельно разрешите необходимые изменения в отдельной ветке, запустите тесты и создайте Pull Request. Вход через меню по умолчанию — **read-only sandbox**, а не право автоматической публикации.
5. Проверьте PR в GitHub и отчёты **Operations tests** и **Site quality**. Публикующая ветка Pages может отличаться от `main`: слияние PR не гарантирует обновление сайта.

## Многоязычный черновик без оплаты AI-провайдера

Меню **4** использует только синтетические сведения. Действительное содержимое из CRM или заказов не загружается автоматически. Результат `QA_BLOCKED` (код выхода 2) означает потерю важного факта или отсутствие признаков нужного языка: **такой текст не публикуется**. Даже `LOCAL_MODEL_RESPONDED_FACT_TOKENS_PASS` не разрешает публикацию: нужна человеческая проверка смысла, языка, прав на медиа, цены, срока и юридического лица.

На прежнем живом тесте Qwen3 `0.6b` сохранил дату и цену, но **не перевёл** значительную часть текста на русский/украинский/чешский. Он подходит для проверки работоспособности, не для готовых коммерческих объявлений. Если отдельно установлена `qwen3:4b`, код предпочитает её; **установка и качество 4B пока не подтверждены**. Меню не скачивает новые модели и не тратит деньги.

Для **утверждённого публичного исходника** есть более низкоуровневый инструмент:

`node ops/ai-content-pipeline.cjs --input approved-public-row.json --live --translation ollama --output local-draft.json`

Он работает только при наличии локальной модели, утверждённого исходника, действительных прав и продавца, с `job_id` той же строки существующего `SocialPublishing`. Итог — только локальный черновик `REVIEW_REQUIRED` или `QA_BLOCKED`. **Отправки в соцсети, CRM и Google Drive не происходит**. Если нет установленной 4B, можно явно задать `OLLAMA_MODEL=qwen3:0.6b` — но это не делает её пригодной для коммерческой публикации.

## Что ещё не подключено и как снять блокировки

- **Google Antigravity**: `agy 1.4.5` ранее был установлен и показывал модели, но реальный вызов был отклонён: **Google account eligibility failed**. Меню 7 открывает CLI; подтвердить аккаунт можно только лично в разрешённом окне браузера. Не обходить ограничения eligibility/MFA.
- **GitHub Copilot**: Copilot Chat встроен в актуальный VS Code, но установленная программа не доказывает авторизацию или свободную квоту. После входа проверьте статус в интерфейсе.
- **Codex**: в предыдущем тесте `codex login status` показывал **Logged in using ChatGPT**, но автоматическое агентское код-ревью не было подтверждено результатом. Меню 6 открывает сессию на чтение для реальной работы.
- **Microsoft 365 Copilot / Outlook / SharePoint / Power Automate**: Outlook Graph ранее вернул `401`, SharePoint — **no SPO license**. Требуется настоящая лицензия/права администратора. Не вводить карты, не заключать годовой контракт, не менять DNS/MX и не покупать Copilot ради проверки.
- **Remote Desktop Commander**: отдельный мост для команд ChatGPT на вашем ПК. Состояние устройства online нужно только для удалённых действий. Ни PR, ни календарь не включают компьютер автоматически.

## Правило результата

Отдельно учитывайте **установлен инструмент**, **есть авторизация**, **модель ответила**, **содержание прошло QA**, **подтверждёно действие на платформе**, **поступила оплата**. Никогда не подменяйте один статус другим.

Технические детали: [AI toolchain](AI-TOOLCHAIN.md), [AI content pipeline](AI-CONTENT-PIPELINE.md), `AGENTS.md`. Все сценарии — в **существующем репозитории**, без новой CRM или очереди.
